ASIGNATURA: SISTEMAS DE DATOS PARA LA GESTIÓN

SIGLA: SIS216

CRÉDITOS: 3

Horas Prácticas: 2

**Horas Teóricas:**1

PREREQUISITO: SIS123

*OBJETIVO DE LA ASIGNATURA:* Desarrollar competencias técnicas para gestionar, analizar y automatizar datos empresariales mediante el uso de bases de datos relacionales, lenguaje SQL, herramientas de visualización y conectores digitales, de manera que el estudiante será capaz de construir soluciones prácticas orientadas a la toma de decisiones y a la optimización de procesos en entornos organizacionales.

*APORTE AL PERFIL PROFESIONAL:* Esta asignatura fortalece al futuro profesional en el dominio de sistemas de gestión de datos como recurso estratégico para las organizaciones porque le permite comprender la estructura y el funcionamiento de bases de datos, crear consultas en SQL, generar informes visuales y aplicar herramientas de automatización digital. Estas capacidades resultan clave para liderar procesos basados en información, mejorar la eficiencia operativa y responder con agilidad a los desafíos de la transformación digital en empresas y entidades públicas o privadas.

Contenido minimo
Tema 1. Introducción y Práctica con Bases de Datos Relacionales
Conceptos clave: tablas, registros, relaciones, claves.

Uso de hojas de cálculo avanzadas como base de datos (Excel, Google Sheets con filtros y tablas relacionales).

Comparación entre hojas de cálculo y SGBD (Sistemas de Gestión de Bases de Datos).

Tema 2. Manejo Básico de Sistemas de Gestión de Bases de Datos (SGBD)
Introducción a herramientas SGBD: Access, MySQL, Google Tables, Airtable.

Crear, modificar y eliminar tablas y registros.

Propiedades de campo, tipos de datos y buenas prácticas de modelado.

Tema 3. Relaciones, Consultas y Análisis Avanzado
Diseño de relaciones: uno a uno, uno a muchos, muchos a muchos.

Edición y gestión de relaciones.

Consultas simples y avanzadas (selección, parámetros, resumen, referencias cruzadas).

Consultas de acción (actualización, eliminación, creación de tablas y datos anexados).

Tema 4. Introducción al Lenguaje SQL y Automatización
¿Qué es SQL? Importancia en la gestión empresarial.

Estructura básica: SELECT, INSERT, UPDATE, DELETE.

Consultas básicas de extracción y manipulación de datos.

Diseño de formularios para captura de información (Access, Google Forms conectado a base de datos, AppSheet).

Tema 5. Informes, Visualización y Toma de Decisiones
Creación y personalización de informes.

Herramientas para visualización y presentación de datos.

Integración de informes con dashboards básicos (Power BI, Google Data Studio opcional).

Tema 6. Automatización Empresarial y Conectores Digitales
Introducción a la automatización de procesos con datos empresariales: casos prácticos (notificaciones automáticas, generación de reportes, actualización de registros).

Uso de conectores (Zapier, Power Automate, integraciones simples) para flujos de trabajo digital.
